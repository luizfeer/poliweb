🧱 Home Builder

Sistema de blocos reordenáveis pra montar a home pública de cada cidade. Inspirado na home do app Amazon (carrosséis com vídeo, atalhos circulares, listagens segmentadas, faixas de oferta).

Quem mexe

  • city_admin (e super_admin) edita a home da sua cidade em /painel/cidade/home.
  • RLS faz a checagem via public.is_city_admin(city_id). Leitura é pública.

Modelo de dados

custom_hero_banner usa home_block_banners para a imagem unica e guarda layout, textos, cores, fonte, overlay, posicao e animacao em home_blocks.config.

  • home_layouts — 1 linha por cidade. Criado on-demand pela função ensure_home_layout(city_id).
  • home_blocks — blocos do layout. Campos: type (enum), position, enabled, title, config jsonb.
  • home_block_banners — filhos de blocos do tipo banner_carousel. FK pra media_assets (imagem obrigatória, vídeo opcional). Link interno/externo + janela start_at/end_at.

Tipos de bloco (MVP)

  • banner_carousel — slides com vídeo que toca uma vez e dá fade pra imagem. Imagem é obrigatória, vídeo opcional. Suporta link interno (router), externo (new tab), ou nenhum. Janela de exibição opcional.
  • category_grid — atalhos circulares (RoundCat) configuráveis: label, ícone lucide, href, tom de cor.
  • entity_list — listagem dinâmica de uma fonte: businesses_featured, businesses_recent, tourism_attractions, tourism_lodgings, city_promotions. Limite e CTA configuráveis.
  • promo_strip — faixa horizontal de cupons ativos.

Hero personalizavel

  • custom_hero_banner tem modelos de comercio, evento, turismo e oferta.
  • O editor controla imagem, posicao X/Y, texto, CTA, cores, fonte, altura, full-bleed, overlay e animacao.
  • A action de banners aceita o tipo como bloco de midia unica.

Renderer

app/page.tsx consulta getHomeLayoutForRender(cityId). Se a cidade tem layout do builder, renderiza <HomeRenderer /> mesmo quando todos os blocos estao ocultos ou removidos. O layout hardcoded antigo fica apenas como fallback para cidades sem layout configurado.

Banner com vídeo → imagem

  • Imagem sempre presente como base.
  • Vídeo (se houver) sobreposto com autoplay muted playsInline preload="metadata".
  • IntersectionObserver pausa quando o slide sai da viewport.
  • Ao terminar (onEnded) ou falhar (onError), faz fade-out e revela a imagem.

Port para React Native

O contrato é o schema do config, não o JSX. Cada bloco tem schema documentado em components/public/home/blocks/README.md com dicas específicas pra reimplementação nativa (expo-av, FlatList horizontal, viewabilityConfig, etc).

Extensibilidade

  1. Adicionar valor no enum home_block_type.
  2. Tipar config em lib/home/types.ts.
  3. Registrar em lib/home/block-catalog.ts (label, descrição, defaultConfig).
  4. Criar componente em components/public/home/blocks/.
  5. Adicionar case em HomeRenderer.tsx.
  6. Documentar no README dos blocos.
