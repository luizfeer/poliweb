🏗️ Arquitetura técnica

Stack híbrida: web serverless, dados no Supabase e worker de coleta em VPS.

Princípios

  • RSC por padrão — fetch direto no servidor, hidratação só onde precisa
  • Server Actions para mutations (sem rotas REST extras)
  • RLS no Supabase é a fonte de verdade da autorização — middleware é apenas refresh de token
  • Worker VPS para jobs longos de scraping, IA e embeddings
  • Edge Functions só para callbacks leves, triggers e fallback
  • ISR nas listagens públicas (pousadas, eventos, telefones) — revalidate 60s
