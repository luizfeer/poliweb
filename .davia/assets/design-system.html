🎨 Design System — Carmo Local

Linguagem visual densa estilo Amazon mobile, com identidade do interior mineiro. Mobile-first, base 16px, frame de design 390-430px.

Inspiração e diferenciação

  • Densidade Amazon: cards justapostos, banners coloridos, ícones de categoria, listagens curtas
  • Identidade mineira: laranja-telha (não laranja-Amazon puro) referenciando solo da Canastra e entardecer em Furnas
  • Tipografia com personalidade: Fraunces (serifa moderna) em displays + Inter no corpo
  • Off-white quente (paper #FAF8F5) — não branco frio

Tokens e paleta

Definidos em apps/web/app/globals.css e expostos como utilidades Tailwind v4 via @theme inline:

  • Clay (primária): bg-clay-500 (#E0561B), bg-clay-600 (hover), bg-clay-50 (tint)
  • Cerrado (verde): turismo, natureza, confirmações
  • Sun (amarelo): ratings, "novo", destaques sutis
  • Sky (azul cidadania): links, transparência, secundários
  • Discount (magenta-vinho): APENAS em badges de oferta — não é destrutivo
  • Ink: ink-900 (texto), ink-600 (secundário), ink-300 (bordas)
  • Paper: paper (página), paper-card (cards), paper-deep (faixas de seção)

Tipografia

  • Display: Fraunces (Google Fonts) — pesos 500, 600, 800
  • UI / corpo: Inter (Google Fonts) — pesos 400, 500, 600, 700
  • Mono: JetBrains Mono — raros números técnicos
  • Carregadas via next/font em app/layout.tsx com display swap

Componentes

Implementados em apps/web/components/carmo/. Todos Server Components por padrão (zero JS no cliente quando possível).

Vozes e tom

  • PT-BR sempre, tratamento "você", sotaque interior mineiro sem caricatura
  • Sentence case em títulos e labels ("Coleta de lixo", não "Coleta de Lixo")
  • EXCEÇÕES title case: nomes próprios (Ilha do Chico, Serra da Canastra, Festa do Padroeiro)
  • Sem emoji em UI estrutural — usar Lucide icons (stroke 1.75)
  • Conteúdo IA sempre com badge "Resumido por IA — sujeito a verificação" + link pra fonte

Iconografia

Lucide React instalado. Tamanhos padrão: 16 (inline), 20 (input/button), 24 (default), 30 (categoria).

import { Trash2, HeartPulse, Fish } from 'lucide-react';

Como usar (página Server Component)

import { AppFrame, AppHeader, HeroBanner, RoundCat, TabBar } from '@/components/carmo';
import { Trash2 } from 'lucide-react';

export default function Home() {
  return (
    <AppFrame>
      <AppHeader cep="37150-000" />
      <HeroBanner kicker="Domingo na represa" title="Ilha do Chico" />
      <RoundCat label="Lixo" icon={Trash2} bg="clay" />
      <TabBar active="home" />
    </AppFrame>
  );
}
