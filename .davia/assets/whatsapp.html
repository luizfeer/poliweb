WhatsApp Hub

Integracao oficial com a Meta WhatsApp Cloud API. Dois canais por cidade.

Canal transacional envia confirmacoes, lembretes e alertas via templates aprovados.

Canal assistente recebe perguntas livres e responde usando o agente de cidade ja existente.

Componentes

  • apps/web/lib/whatsapp/meta-client.ts faz wrapper da Graph API.
  • apps/web/lib/whatsapp/templates/ guarda templates como codigo TS versionado.
  • apps/web/lib/whatsapp/sync-templates.ts faz diff entre local e Meta.
  • apps/web/lib/whatsapp/outbound.ts expoe enqueueTemplate() para Server Actions.
  • supabase/functions/wa-webhook recebe mensagens da Meta com HMAC.
  • supabase/functions/wa-outbound-worker processa fila a cada minuto via cron.

Fluxo outbound

  • Server Action chama enqueueTemplate() apos um evento de negocio.
  • Linha entra em wa_outbound_queue com status pending.
  • Cron dispara wa-outbound-worker a cada minuto.
  • Worker pega lote de 25, envia via Graph API e cria linha em wa_messages.
  • Status updates posteriores chegam via webhook e atualizam sent_at, delivered_at, read_at.
  • Suporta kind = interactive para mensagens com botoes de resposta (usado pelo delivery: Aceitar / Recusar / Ver pedidos).

Fluxo inbound

  • Meta entrega payload em POST /functions/v1/wa-webhook.
  • Webhook valida HMAC com META_WA_APP_SECRET e responde 200 em menos de 5 segundos.
  • Mensagem entra em wa_messages com direction in.
  • wa_touch_session() renova a janela de 24 horas do contato.
  • O webhook enfileira em wa_inbound_queue com a coluna consumer: canal assistente vai para o worker IA; canal transacional vai para o delivery-bot.
  • Worker IA consome consumer = assistant, chama city-agent-client e responde.
  • delivery-bot consome consumer = delivery_bot, interpreta comandos e botoes do operador e atualiza o status do pedido. Ver delivery-orders.html.

Templates como codigo

  • Cada template eh um modulo TS tipado em lib/whatsapp/templates/.
  • Script pnpm tsx scripts/wa-sync-templates.ts envia novos templates para Meta.
  • Meta nao permite editar body de template aprovado. Mudancas de texto criam template novo com sufixo de versao.
  • Status remoto vira espelhado em wa_templates.

Multi-cidade

  • Cada cidade tem ate dois canais via wa_channels com constraint unique em (city_id, kind).
  • Webhook resolve cidade pelo phone_number_id recebido.
  • RLS filtra wa_messages por canal e cidade.

LGPD

  • wa_opt_ins guarda consentimento granular por tipo: transacional, marketing, assistente.
  • Marketing exige opt-in explicito. Transacional segue base legitima de execucao de contrato.
  • Revogacao gera revoked_at e bloqueia envios futuros via verificacao no worker.
